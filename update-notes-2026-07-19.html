Update notes, July 19, 2026

(c.ai) reads: rebuild, rebrand, and UX overhaul

New component architecture, Tailwind styling, brand design system, reworked UX on every screen, and a long list of fixes.

Architecture

  • The entire interface was rebuilt with proper, reusable React components. Things that used to be copy-pasted in five places (cards, menus, buttons, badges, popovers, tabs) are now built once and shared everywhere, so they cannot drift apart and future changes happen in one spot.
  • All styling was migrated to Tailwind, wired to a single set of design tokens. Every color, radius, shadow, and spacing value comes from one source of truth, which is what makes the three themes (light, paper, dark) work reliably.
  • Animations were rebuilt on a real motion system instead of ad-hoc CSS, so panels, pills, and page elements move with consistent physics.
  • Dead code was swept out, duplicated logic was consolidated, and the data layer was tuned so pages load less duplicate data and build faster.

Brand and visual design

  • Full rebrand to (c.ai) reads: new logo, favicon, social preview images, and search-engine metadata.
  • The color system now comes straight from Character's design kit: quill ink, espresso, pinned purple, the hot brights for badges. The site looks like it belongs to the brand instead of a generic archive.
  • The UI was pushed toward a polished product feel: rounded corners everywhere, soft pill-shaped controls, frosted glass buttons on the banners, plush toggles, and consistent card chrome.
  • The five rating badges got a new cool-to-hot color ramp (icy blue up to magenta) with letters that stay readable on every background.

UX changes

  • Reading page: one unified floating control system, a bottom dock with the story, chapter, and "Your place" pills, locked-chapter previews, and soft top and bottom fades (now edge-free on iPhone).
  • Browse and home: a new header and navigation system, the hero carousel, editorial shelves, and a floating filter panel that pushes the page aside instead of covering it.
  • Library and characters: proper toolbars, a tab rail with a sliding indicator, scoped search and sorting per tab, and empty-state cards that explain how each section fills up.
  • New pages: About and Writers, plus character chat and imagine dialogs from the fandom hub.
  • Mobile got its own pass: a real site menu, a filter experience built for small screens, touch-friendly controls, and headlines that wrap cleanly.
  • Accessibility went from 756 automated violations to zero, WCAG 2.2 AA, across every page and all three themes. Keyboard navigation, focus handling, contrast, and dialog behavior were all fixed for real.

Fixes

  • The page-menu underline no longer flies across the screen when you switch pages after scrolling.
  • The "Your place" button appears and disappears smoothly, with no stutter or overlap, and stands out in espresso brown.
  • The chapter progress bar is purple now and actually visible in every theme.
  • Loading placeholders are simpler (no more moving shine), match the current theme, and carry the same outline as real cards.
  • The mode toggle no longer flashes the wrong position when a page loads.
  • The carousel dots are evenly spaced no matter which slide is active, and identical on phone and desktop.
  • The smallest text anywhere on the site is now 10px.
  • Tooltips, hydration flashes, filter races, and a long tail of similar paper cuts were hunted down and fixed.

New: the demo page

There is now a page at /demo that shows the parts of the site you normally cannot see just by browsing. It has the account menu in both states, signed out (with the new "Sign in with c.ai" prompt) and signed in, plus every "this section is empty" card and the loading placeholders. Each one has a short note saying exactly where it appears on the real site. It is not linked from anywhere and search engines are told to ignore it, so it is safe to share internally.

All changes are on the ux-audit branch.
